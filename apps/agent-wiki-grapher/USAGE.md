# AgentWikiGraph 사용법

일반 창 앱 — 실행하면 바로 주 창이 열린다(메뉴바 없음).
첫 실행은 사용법 온보딩(기능 소개 + [시작하기], 한 번만)이 뜬다.
설정(⌘,)에서 언어(System/한국어/English)를 즉시 전환할 수 있다.

CLI 바이너리 이름: `agent-wiki-graph` (executable product `AgentWikiGraph`).

의존성: `agent-wiki-graph capabilities` → `.result.depends` (목록은 여기 두지 않는다.
정본: `docs/app-interop-contract.md`).
